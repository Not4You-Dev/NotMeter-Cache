The files are unmodified 1920×1080 WebP originals from the approved previews.
Only the selected day's image is requested. Color grading, haze and particles
are CSS layers, respecting reduced motion and pausing while the tab is hidden.

The calendar begins with option 5 on 2026-10-10 in Asia/Seoul (UTC+09:00).
All visitors use the same deterministic daily sequence. A nonzero randomized
step through the five scenes prevents consecutive duplicates. The date does
not depend on UI language, browser timezone, storage or a server request.
