# 랭커 직업 아이콘 테두리 미리보기

홈페이지의 **구간 랭킹·닉네임 효과 안내**에 사용할 이미지입니다. 이 변경은 미리보기 자산만 추가하며 홈페이지 화면, 랭킹 판정, 닉네임 효과 권한은 변경하지 않습니다.

## 파일과 표시 조건

모든 예시는 같은 검성 직업 아이콘을 사용합니다. 숫자는 해당 이미지의 예시 순위이며, 테두리 색과 순위 숫자의 색은 별개입니다. 숫자 색은 미터기의 직업/강조색 설정에 따라 달라질 수 있습니다.

| 파일 | 설명 | 예시 숫자 |
| --- | --- | --- |
| `unranked.png` | 랭커 표시가 없는 기본 직업 아이콘 | 없음 |
| `rank-11-20.png` | 대표 순위 11~20위: 보라색 모서리와 오른쪽 위 보석 | 20 |
| `rank-6-10.png` | 대표 순위 6~10위: 하늘색 모서리와 오른쪽 위 보석 | 10 |
| `weekly-rank-1-5.png` | 이번 주 1~5위이며 전체 기간 TOP5가 아닌 경우: 금색 모서리와 오른쪽 위 보석 | 5 |
| `alltime-rank-1-5.gif` / `.png` | 전체 기간 1~5위: 금색 다이아몬드, 하단 광선과 테두리를 도는 광점. PNG는 정지 미리보기 | 5 |

`rank-6-10.png`와 `rank-11-20.png`의 모양은 전체 기간과 이번 주에 공통입니다. 전체 기간 TOP5 조건이 있으면 일반 모서리 테두리보다 다이아몬드 효과가 우선합니다. 이번 주 TOP5만으로는 다이아몬드 효과가 생기지 않습니다.

## 안내에 반드시 구분할 기준

- 랭커 마크 대상은 CP 800K 이상 캐릭터의 대상 던전·보스, 같은 직업, 현재 CP 구간에서 **전체 기간 DPS 또는 이번 주 nDPS TOP20**입니다. CP 구간은 25K 단위이며 2M 이상은 하나의 구간입니다. 악몽 등 처치 시간 순위 콘텐츠의 기존 예외는 유지해야 합니다.
- 직업 아이콘의 숫자는 두 기간의 해당 순위 중 **가장 높은 순위(작은 숫자)**입니다. 전체 기간 TOP5의 움직임 여부는 별도로 전체 기간 순위만 확인합니다.
- 1~5위는 금색, 6~10위는 하늘색, 11~20위는 보라색 모서리입니다. **전체 기간 1~5위는 움직이는 다이아몬드로 바뀝니다.**
- **랭커 테두리 TOP20 / 전체 기간 다이아몬드 TOP5 / 랭킹에 따른 닉네임 효과 권한 TOP3**를 같은 조건처럼 설명하지 마세요. 칭찬 TOP20 등 별도 닉네임 효과 권한과도 구별해야 합니다.
- 대상 던전, 제외 조건, 캐시 갱신 시점, 미터기의 랭커 표시 설정은 홈페이지 통합 시 최신 소스와 기존 안내를 대조하세요. 이 이미지가 새로운 자격이나 보상을 추가하는 것은 아닙니다.

## 홈페이지에서 사용할 때

- `manifest.json`에 파일별 제목, 대체 텍스트, 예시 순위, GIF/PNG 연결이 있습니다.
- 원본은 **192 × 192px**, 표시 권장은 **96 × 96 CSS px**입니다. 확대 설명이 필요하면 최대 원본 크기까지 사용하고 가로세로 비율을 유지하세요.
- PNG와 GIF 모두 **불투명 배경 `#171e24`**입니다. 어두운 미리보기 면 안에서 두 테마에 공통으로 사용하세요. GIF의 1비트 투명도로 광선 가장자리를 훼손하지 않기 위한 선택입니다. 색상 필터나 테두리 재현 CSS를 추가하지 마세요.
- GIF는 클라이언트의 6.128초 주기를 GIF 시간 단위에 맞춰 **6.13초로 반복**합니다. 하단 선 등장 → 0.76초부터 3초간 광점 이동 → 멈춤까지 담았습니다.
- 안내를 펼쳤을 때 정지 이미지와 **움직임 보기 / 멈추기** 조작을 바로 발견할 수 있게 배치하세요. 안내가 닫혀 있으면 GIF를 불러오지 말고, 정지 시에는 같은 이름의 PNG로 교체하세요.
- `prefers-reduced-motion: reduce`에서는 기본적으로 PNG를 사용하세요. 사용자가 직접 움직임 보기를 선택한 경우에만 GIF를 재생할 수 있습니다. 모든 예시를 동시에 자동 재생할 필요는 없습니다.
- 순위·조건·움직임 여부는 이미지 밖의 텍스트로도 제공하세요. 이미지 속 숫자만으로 조건을 설명하지 마세요.
- `assets/ranker-previews/...`와 같은 동일 사이트 상대 경로로 사용하세요. GitHub 원문 주소를 런타임 이미지 CDN처럼 연결하지 마세요.

랭커 렌더링·기간별 순위 관련 기존 테스트 92개 통과. 이미지 크기, 두 GIF의 서로 다른 프레임, 반복 시간, 배경색, 파일 해시와 실제 렌더링을 확인했습니다. 제작 도구 및 개별 프레임은 이 PC의 무시 경로 `work/ranker-border-previews/`에 보관합니다.
